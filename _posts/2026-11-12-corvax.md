JavaScript library that lets peers find each other by key or by topic and open an encrypted WebRTC DataChannel, directly or relayed through another peer. Addresses are Ed25519 keys generated locally; there is no registration and no central server. Anchors are ordinary peers that only introduce other peers and are never in the data path; anyone can run one. Topics carry signed, leased presence and short best-effort broadcasts. No runtime dependencies and no build step; runs in browsers, Node, Bun and Deno. Published on npm as @sloev/corvax, with an adapter for Trystero.
