body_en: JavaScript library that lets peers find each other by key or by topic and open an encrypted WebRTC DataChannel, directly or relayed through another peer. Addresses are Ed25519 keys generated locally; there is no registration and no central server. Anchors are ordinary peers that only introduce other peers and are never in the data path; anyone can run one. Topics carry signed, leased presence and short best-effort broadcasts. No runtime dependencies and no build step; runs in browsers, Node, Bun and Deno. Published on npm as @sloev/corvax, with an adapter for Trystero.

JavaScript-bibliotek, hvor peers finder hinanden via nøgle eller emne og åbner en krypteret WebRTC DataChannel, direkte eller videresendt via en anden peer. Adresser er Ed25519-nøgler genereret lokalt; der er ingen registrering og ingen central server. Ankre er almindelige peers, der kun introducerer andre peers og aldrig indgår i datavejen; alle kan køre ét. Emner bærer signeret, tidsbegrænset tilstedeværelse og korte broadcasts uden leveringsgaranti. Ingen runtime-afhængigheder og intet build-trin; kører i browsere, Node, Bun og Deno. Udgivet på npm som @sloev/corvax, med en adapter til Trystero.
